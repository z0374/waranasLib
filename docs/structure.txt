# 💾 Estrutura do Registro BIN

```text
256 Bytes

┌────────────┬──────────────────────────────┬─────────────────────────────┐
│ Byte 0     │ Byte 1 → 32                  │ Byte 33 → 255               │
├────────────┼──────────────────────────────┼─────────────────────────────┤
│ 📌 Status  │ 🏷 Termo (32 Bytes)          │ 📂 Conteúdo (223 Bytes)     │
└────────────┴──────────────────────────────┴─────────────────────────────┘
```

# 🎯 Filosofia

A Waranas Library é dividida em quatro grandes camadas:

- 🧠 **Services** → regras de negócio.
- ⚙️ **Protocols** → armazenamento e algoritmos.
- 🧱 **Components** → interface reutilizável.
- 🌐 **API/Core** → integração com aplicações.

Essa arquitetura mantém cada módulo com uma responsabilidade única, facilitando reutilização, manutenção e desempenho.
